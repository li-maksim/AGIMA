# Тестовое задание

Тестовое задание для позиции стажера PHP-разработчика (Bitrix).  

## Описание проекта

Репозиторий содержит 3 задания: 
- Форма обратной связи: `task1.php`, `index.php`, `styles_task1.php`.
- Функция, определяющая общую стоимость товаров из массива: `task2.php`.
- Класс для работы с книгами: `task3.php`.

## Запуск

Для запуска проекта должен быть установлен PHP.  

**Задание 1**. Открыть папку проекта в терминале и выполнить команду `php -S localhost:8000`. Это откроет сайт на локальном сервере по адресу `localhost:8000`.  
  
**Задание 2**. Выполнить команду в терминале: `php -r "require 'task2.php'; echo calculatePrice(МАССИВ);"`. Будет посчитана общая стоимость товаров с учётом скидок. 
Вместо МАССИВ можно вставить тестовый массив `$shoppingCart1` или `$shoppingCart2`. Для их использования знаки `$` нужно экранировать с `\`: `php -r "require 'task2.php'; echo calculatePrice(\$shoppingCart1);"`
  
**Задание 3**. Выполнить команду: `php task3.php`. Будет выведена информация о книгах.
